TL MOBILE — добавление почасовой услуги

Источник: https://www.figma.com/design/HJqHBF2aSgjUoYtrysofG4/TL-MOBILE?node-id=48181-77732
Локальный адрес: http://127.0.0.1:4174/

Запуск: node server.mjs
Проверки: node --test tests/model.test.mjs
Проверка синтаксиса: node --check app.js
Требуется Node.js 20+. Установка пакетов не нужна.

Основной путь:
Услуги в номере → Добавить услугу → Почасовая → Группа/Услуга →
Дата → Начало → Сотрудник → Место → Инвентарь → Возраст →
Количество → Счёт/Комментарий → Добавить услугу → результат.
Селекторы открываются отдельными экранами, отмена сохраняет форму.
Основной случай: парная на 27 ноября, 11:00–11:45, 1500 RUB.
Если ресурсы уже заняты ранее добавленной услугой, выберите другой
свободный интервал или оставшийся ресурс. 12:00 доступно в актуальном макете.

Согласованные и явно принятые трактовки:
- Пользователь выбрал 23–29 ноября 2026 по карточке брони вместо
  мартовских дат, оставшихся в некоторых экранах Figma.
- Демо-дата зафиксирована: 24 ноября 2026. В примере запрет продаж
  за 3 дня закрывает 24–26 ноября; 28 ноября полностью занято.
- Дата выезда доступна после выезда в 12:00 в пределах часов услуги.
- В основной парной есть сотрудник, место, инвентарь и возраст.
  Для взрослого и ребёнка парная стоит 1500 RUB согласно этой секции.
  Возрастной тариф бассейна: 1500/750 RUB. Цена не редактируется.
- «Без категории» фильтрует только услуги без группы. В Figma от
  этого пункта проведена связь к экрану с заголовком «Все услуги»;
  фильтрация сохранена по функциональной спецификации.
- Неполные и внешние переходы Figma замкнуты внутри локального сценария.
- Общие услуги открывают просмотр существующих общих услуг брони;
  интерактивное добавление реализовано для запрошенных почасовых услуг.

Ресурсы проверяются на весь интервал, включая продление и уже добавленные
услуги. Единственный свободный ресурс назначается автоматически.
Количество не зависит от двух проживающих и ограничено вместимостью.
Новый индивидуальный счёт текущего номера создаётся вместе с начислением.
Комментарий ограничен 255 символами. Создание и редактирование защищены
от повторной отправки; устаревшее редактирование не воссоздаёт удалённую запись.

Данные сохраняются в localStorage только этого браузера, отдельно от
предыдущего прототипа. Сброс выполняется кнопкой на панели демонстрации.
PMS не подключён: транзакция и конфликты демонстрационные. Настоящую
защиту от конкурентного овербукинга должен обеспечивать сервер PMS.

assets/*.svg экспортированы из исходной секции Figma без перерисовки.
Roboto загружен из официального репозитория Google Fonts, лицензия в assets/Roboto-OFL.txt.
